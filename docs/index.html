Start in a minute

Docker

docker run -d --name h2s-alerts --restart unless-stopped \
  -e H2S_CITIES="Eindhoven, Rotterdam" \
  -e H2S_PRICE_MAX=1600 \
  -e H2S_NOTIFY="tgram://BOT_TOKEN/CHAT_ID" \
  -v h2s-data:/data -p 127.0.0.1:8080:8080 \
  ghcr.io/kooroshkz/holland2stay-alerts

Dashboard on localhost:8080. Runs on a Raspberry Pi too.

Python

pipx install git+https://github.com/kooroshkz/holland2stay-alerts
h2s-alerts init
h2s-alerts watch

init asks a few questions and sends a test message.

What you get

Your search

Cities, bedrooms, budget, contract length, furnishing, move-in date.

Only what's new

New homes, homes back on the market, lottery homes that turn bookable, price drops. Never the same one twice.

Lottery

New lottery homes on Tuesday evening, with the Sunday 20:00 deadline.

Early warning

New buildings appear in the catalog weeks before they go on sale. You hear about them first.

Dashboard

What's available, what got taken and how fast, and the hours homes usually show up.

Polite by design

A check every few minutes, faster in the hours homes are released. It says who it is and backs off when asked.

Questions

Does it book homes for me?

No. It tells you, you book on the Holland2Stay website yourself. Automated booking is against their terms. Keep a browser tab open and stay logged in so you're one click away.

How fast are the alerts?

Usually within two minutes during weekday release hours, a few minutes the rest of the day. Cheap homes in big cities can still go within a minute, so be ready to act.

Do I need a server?

No. Any computer that stays on works: a laptop on power, a Raspberry Pi, a NAS or a small VPS.

What about the lottery?

Lottery homes come out on Tuesday around 17:00 and you can sign up until Sunday 20:00. You get a message when ones matching your search appear.

Holland2Stay is becoming Codomo. Will it still work?

That's the plan. When listings move, set base_url to the new site or update to the latest version.
